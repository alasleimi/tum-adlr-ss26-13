# SimbaV2 + SACn Report

Generated: 2026-06-25

This report compares three grid-evaluated agents:

- `simba_full_official_opt`: plain SimbaV2 SAC baseline at 100k.
- `simba_full_official_opt_sacn16`: density-weighted SACn with `n=16` at 100k.
- `simba_full_official_opt_nois_sacn8_soft_stop10k`: no-importance soft SACn with `n=8` for the first 10k steps, then plain SimbaV2 SAC to 100k.

The decision metrics here are task success and reference-relative success against `max(DP, controller)`. Fixed return success is shown only as a diagnostic, not as a success criterion.

## 1. What SACn Is

SACn is Soft Actor-Critic with n-step critic targets. Plain SAC trains the critic with a one-step soft Bellman target:

```text
Q(s_t, a_t) <- r_t + gamma * [Q_target(s_{t+1}, a') - alpha log pi(a' | s_{t+1})]
```

SACn samples contiguous replay sequences and trains the critic with multiple longer-horizon targets:

```text
Q(s_t, a_t) <- r_t
             + gamma r_{t+1}
             + ...
             + gamma^(k-1) r_{t+k-1}
             + gamma^k [Q_target(s_{t+k}, a') - soft entropy terms]
```

for horizons `k = 1..n`.

The intended benefit is faster reward propagation: instead of waiting for value information to move back one Bellman update at a time, the critic directly sees multi-step returns from real replay trajectories.

The off-policy issue is that those replay actions were generated by older policies. Official SACn therefore computes trajectory density ratios, roughly:

```text
omega_k = product_i pi_current(a_i | s_i) / pi_behavior(a_i | s_i)
```

and uses clipped/truncated/scaled versions of these weights in the critic loss. In this repo, the official-style implementation is `sacn_importance_mode="density"`. The experimental stop10k variant uses `sacn_importance_mode="none"`, so the multi-step targets are unweighted by density ratios and are only used as an early training phase.

- Official SACn repo inspected locally during the experiment: https://github.com/lychanl/sacn
- Our combined implementation: `src/last_nine_rl/sac.py`

## 2. Importance Weight Collapse Check

I checked the existing saved hard-start horizon diagnostic before including the collapse claim. The artifact is:


It was produced by:


using the density-weighted SACn32 recent+ESS run:

```text

```

The saved diagnostic is a hard-start diagnostic: the `all` and `hard_down_abs_theta_ge_150_abs_vel_le_1` rows have the same count, so every sampled start in this artifact satisfies the hard-down mask.

Result: for these hard-start sampled sequences, the final-horizon importance weights collapse to zero for every horizon tested.

| horizon | samples | median final log omega | final-horizon ESS fraction | final weight <= 1e-3 | active horizons | final weight mean |
|---:|---:|---:|---:|---:|---:|---:|
| 4 | 2048 | -149.4 | 0.000 | 1.000 | 1.0 | 0 |
| 8 | 2048 | -311.7 | 0.000 | 1.000 | 3.0 | 0 |
| 16 | 2048 | -1951.3 | 0.000 | 1.000 | 9.0 | 0 |
| 32 | 2048 | -6957.2 | 0.000 | 1.000 | 13.0 | 0 |
| 64 | 2048 | -9400.0 | 0.000 | 1.000 | 26.0 | 0 |

Interpretation: the product density ratio is not merely noisy in these hard-start states; it underflows/collapses so strongly that the longest-horizon target receives no effective weight. This supports the earlier diagnosis for density-weighted SACn in hard states. It does not apply to the stop10k no-importance variant, because that variant disables density-ratio weighting.

## 3. Grid Results

Comparison grid: 61 theta bins x 41 velocity bins over reset support with `|theta_dot| <= 1`. Reference-relative metrics compare each SAC rollout against DP and controller grids with epsilon return `5.0`.

Important caveat: plain SimbaV2 is a 3-seed grid aggregate, density SACn16 is a 5-seed grid aggregate, and stop10k is currently a seed-0 probe. Seeds 1-4 for stop10k are still running at the time this report was written, so the stop10k row is promising but not yet a final 5-seed result.

### All Reset Support

| agent | grid seeds | task success | near max(DP, controller) eps | beats max(DP, controller) | near controller eps | beats controller | fixed return diagnostic |
|---|---:|---:|---:|---:|---:|---:|---:|
| Plain SimbaV2 100k | 3 | 0.9144 | 0.9250 | 0.0717 | 0.9935 | 0.5727 | 0.6919 |

Reading:

- Density SACn16 improves strict beating metrics, especially `beats max(DP, controller)` and `beats controller`, but it loses task success and near-reference success versus plain SimbaV2. This does not satisfy the target criterion.
- The stop10k variant improves seed-0 task success and near-reference success over the plain SimbaV2 aggregate and also improves strict beating rates versus plain. This is the first promising SACn hybrid found so far, but needs the in-progress 5-seed validation.

## 5. Current Conclusion

The importance-collapse claim is supported for the saved hard-start density-weighted SACn diagnostic: final-horizon weights collapse completely across sampled hard-start sequences.

The 100k density SACn16 result does not meet the desired criterion because it is worse than plain SimbaV2 on task success and near-reference success, even though it beats the references more often in strict return terms.

The stop10k no-importance SACn8 warm-start is the best current candidate. In seed 0 it improves:

- task success: `0.9204` vs plain `0.9144`
- near max(DP, controller) eps: `0.9396` vs plain `0.9250`
- beats max(DP, controller): `0.1283` vs plain `0.0717`
- beats controller: `0.7137` vs plain `0.5727`

This should not yet be treated as final because it is a seed-0 probe. The remaining seeds are running under:

```text
runs/simbav2_nois_sacn8_soft_stop10k_100k_probe/simba_full_official_opt_nois_sacn8_soft_stop10k
```

Once seeds 1-4 finish, the next step is to regenerate the 5-seed grid and relative-success report for the stop10k condition.
