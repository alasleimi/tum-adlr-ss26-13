# Report evidence

`rollouts/` contains one common-grid table per displayed method or ablation.
Each table has 12,505 rows: five actor seeds, 2,501 initial states per seed,
61 angles, and 41 angular velocities. The verifier requires one row for every
seed/state combination and checks metric semantics before recomputing counts.

`diagnostics/` contains the raw rows and summaries used for the nine report
figures. `claims.json` stores integer regression targets, never rounded rates.
`provenance/` records historical lineages and non-isolated contrasts.

Run:

```bash
uv run last-nine verify
```

`manifest.json` is generated by `scripts/build_artifact_manifest.py` and binds
every curated input to a byte size and SHA-256 digest.
